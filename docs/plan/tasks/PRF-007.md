# PRF-007 - Unified cross-backend kernel emitter (Mojo-style codegen)

**Theme:** perf  
**Tier:** performance  
**Deps:** MTL-002, PRF-004

Introduces a unified `PointwiseKernelDef` macro and generator in `incin-backends`
that defines elementwise unary and binary kernel logic once in Rust, emitting
equivalent CUDA C++, WebGPU Shading Language (WGSL), and Metal Shading Language (MSL)
shaders from a single source of truth.

## Steps

1. [x] Create `crates/incin-backends/src/codegen/mod.rs` and `pointwise.rs`.
2. [x] Define a `PointwiseOpSpec` representation describing unary/binary mathematical ops,
   elementwise expressions, data types (`f32`, `f16`, `bf16`, `f64`), layout handling (contiguous, strided, scalar broadcast), and thread indexing.
3. [x] Implement `render_cuda()`, `render_wgsl()`, and `render_msl()` target emitters from `PointwiseOpSpec`.
4. [x] Migrate CUDA pointwise rendering in `incin-backends/src/kernel.rs` to use the unified codegen system.
5. [x] Connect WGPU and Metal backend dispatchers to consume generated shader sources instead of hand-written redundant `.wgsl`/`.metal` pointwise files.
6. [x] Add cross-backend parity unit tests verifying that CUDA, WGSL, and MSL generated code produce identical numerical results across float types.
7. [x] Run `cargo test --workspace`.

## Boundaries

Focuses strictly on pointwise unary and binary kernel generation across CUDA, WGPU, and Metal. Complex multi-stage reductions (warp shuffles, Welford) and backend-specific BLAS/conv matrix multiplication remain in their specialized backend execution paths until graph-level op fusion (CMP-005).
