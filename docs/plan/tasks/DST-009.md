# DST-009 - TP=2 networked linear and attention

The first tensor-parallel topology is exactly two ranks in separate processes
on network-accessible CUDA hosts. The current executable fixture validates
plan construction and NCCL communicator setup; CUDA tensor-kernel parity is
covered by backend-specific capability tests.

1. [x] Define `TwoRankTensorParallel` as
   `MeshSpec<Data<U1>, TensorParallel<U2>, Pipeline<U1>>`.
2. [x] Define `TensorParallelDType`: `f16`, `bf16`, `f32`, `f64`, and `Dyn`.
   Static integer/quantized values are compile errors; `Dyn` rejects the same
   runtime dtypes.
3. [x] Require output-feature, contraction, and attention-head extents to
   divide by two through `ShardDivisible<U2>` statically and the same explicit
   runtime check for `Dyn`.
4. [x] Encode column output as `Sharded -> Replicated` all-gather, row output
   as `Partial<Sum> -> Replicated` all-reduce, and attention heads as
   `Sharded -> Replicated` all-gather on the tensor mesh axis.
5. [x] Give every operation a stable nonzero `TensorParallelId`; include both
   identity and semantic operation kind in preflight so equal-shaped column
   and attention gathers cannot be swapped.
6. [x] Add `TwoWayColumnLinearShape` and `TwoWayRowLinearShape` proofs to the
   ordinary `LinearShape` vocabulary.
7. [x] Prove deterministic column-linear, row-linear, and scaled dot-product
   attention parity on the reference transport for static `f32` and runtime
   `Dyn(F64)`.
8. [x] Add a typed CUDA tensor entry point that validates identity, operation,
   placement, dtype, count, bytes, device, layout, and requested global shape
   before NCCL launch.
9. [x] Reassemble NCCL's rank-major all-gather result on CUDA for arbitrary
   sharded axes; run the non-leading column-axis transform for static and
   `Dyn` on the available GTX 1650 SUPER.
10. [x] Compile the two-host facade harness and run its static and `Dyn` local
    CUDA column-linear, row-linear, and attention computations.
11. [ ] Run the full ignored harness concurrently on two network-accessible
    CUDA/NCCL hosts and record both ranks' numerical parity.

## Local evidence

```text
cargo test -p incin-core --features distributed --test tensor_parallel
5 passed; 0 failed, including 5 compile-fail cases

cargo test -p incin-backends --features distributed-reference \
  --test tensor_parallel_reference
3 passed; 0 failed

cargo test -p incin-backends --features distributed-nccl \
  tensor_parallel_reassembly_moves_rank_axis_on_cuda_for_static_and_dyn \
  -- --ignored --test-threads=1
1 passed; 0 failed

cargo test -p incin --features distributed-nccl,hardware-tests --test tp2_network \
  -- --ignored --exact tp2_plan_and_communicator_initialize
1 passed; 0 failed

cargo test -p incin --features distributed-nccl,hardware-tests --test tp2_network --no-run
compiled
```

The compile-fail cases reject integer values, odd output features, odd input
features, odd attention-head counts, and a DP=2 mesh. Runtime tests reject
integer and quantized dtypes, odd extents, invalid axes, and cardinality
overflow. The CUDA reassembly test covers a batch-two column output sharded on
the non-leading feature axis, so the harness does not rely on a batch-one
layout coincidence.

## Required two-host evidence

```text
# host 0
INCIN_RANK=0 INCIN_WORLD_SIZE=2 INCIN_RUN_ID=tp-example \
INCIN_LOCAL_CUDA_DEVICE=0 INCIN_RENDEZVOUS_ADDR=0.0.0.0:29520 \
INCIN_RENDEZVOUS_TIMEOUT_MS=30000 \
cargo test -p incin --features distributed-nccl,hardware-tests --test tp2_network \
  -- --ignored --exact tp2_static_and_dyn_match_single_device

# host 1
INCIN_RANK=1 INCIN_WORLD_SIZE=2 INCIN_RUN_ID=tp-example \
INCIN_LOCAL_CUDA_DEVICE=0 INCIN_RENDEZVOUS_ADDR=<host-0-ip>:29520 \
INCIN_RENDEZVOUS_TIMEOUT_MS=30000 \
cargo test -p incin --features distributed-nccl,hardware-tests --test tp2_network \
  -- --ignored --exact tp2_static_and_dyn_match_single_device
```

Both ranks must reproduce the one-device column-linear, row-linear, and
attention results for static `f32` and runtime `Dyn(F32)`. Until that output
exists, DST-009 remains active rather than complete.
