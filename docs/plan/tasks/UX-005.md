# UX-005 - `.explain()` and `cargo incin plan` with golden text and JSON reports

Level 1 of §2's UX ladder puts explicit, inspectable execution decisions before any model execution. `UX-005` adds `.explain()` and `.explain_json()` to `Plan` and implements the `cargo incin plan` CLI subcommand.
