# EXE-004 — normalized physical tensor metadata

1. [x] Add backend-neutral `TensorMeta`, `LayoutClass`, and `Alignment` under
   `incin_core::exec::meta`, using `ShapeBuf` and `StrideBuf` rather than raw
   metadata vectors.
2. [x] Make construction validate shape/stride rank, checked view span plus
   offset against allocation capacity, and effective byte alignment.
3. [x] Replace `UnaryLayoutClass`, `BinaryLayoutClass`, and `KernelLayout` with
   the single core `LayoutClass` vocabulary required by decision D-008.
4. [x] Make CPU, CUDA, and WGPU storage carry normalized metadata without a
   second shape/stride/offset source that can drift.
5. [x] Preserve metadata-only CPU transpose, broadcast, narrow, and reshape;
   materializing backends must still report contiguous zero-offset outputs.
6. [x] Add `tensor_meta` integration tests for contiguous, transposed,
   broadcast, nonzero-offset, empty, misaligned, overflow, and out-of-bounds
   views across the available backends.
7. [x] Run the row evidence, no-default/core checks, CUDA/WGPU compile checks,
   formatting, full workspace tests, diff-check, and ledger validation before
   marking complete.
