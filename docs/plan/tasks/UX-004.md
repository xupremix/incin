# UX-004 — #[parallel] and #[shard] template and conflict tests

**Theme:** ux  
**Tier:** preview  
**Deps:** DST-003  
**Target:** `crates/incin-macros/src/module.rs`  

Extends field attribute parsing in `#[module]` for `#[parallel(...)]` and `#[shard(...)]` placement annotations with argument validation, conflict checks, and compile-fail diagnostics.

## Steps

1. [ ] Extend field attribute filtering in `crates/incin-macros/src/module.rs` to process `#[parallel(...)]` and `#[shard(...)]`.
2. [ ] Parse keyword arguments `mesh`, `stage`, `axis`, `dp`, `tp`, `pp`, rejecting unknown arguments.
3. [ ] Check for attribute conflicts (e.g., both `#[parallel]` and `#[shard]` on the same field) and emit clear, span-located `syn::Error` diagnostics.
4. [ ] Strip processed `#[parallel]` and `#[shard]` attributes from emitted struct definitions.
5. [ ] Create integration test `crates/incin-macros/tests/parallel_attrs.rs` and trybuild compile-fail suite in `crates/incin-macros/tests/parallel_attrs_compile_fail/`.
6. [ ] Run `cargo test -p incin-macros --test parallel_attrs`.
