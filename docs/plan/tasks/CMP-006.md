// CMP-006 — Versioned compiled artifacts with compatibility and corruption tests

**Theme:** compile  
**Tier:** preview  
**Deps:** CMP-005  
**Target:** `crates/incin-core/src/compiled/artifact.rs`

Implements a versioned `CompiledArtifact` that wraps a `CompiledPlan` with a version header and a checksum, enabling serialization, compatibility detection, and corruption detection.

## Steps

1. [ ] Create `crates/incin-core/src/compiled/artifact.rs`.
2. [ ] Export `pub mod artifact;` in `crates/incin-core/src/compiled/mod.rs` and re-export key types.
3. [ ] Implement `ArtifactVersion`, `ArtifactHeader`, and `CompiledArtifact` with `serialize`, `deserialize`, and `verify_integrity`.
4. [ ] Create integration test suite `crates/incin-core/tests/compiled_artifact.rs`.
5. [ ] Run `cargo test -p incin-core --test compiled_artifact`.
