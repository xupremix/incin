// CMP-006 - Versioned compiled artifacts with compatibility and corruption tests

**Theme:** compile  
**Tier:** preview  
**Deps:** CMP-005  
**Target:** `crates/incin-core/src/compiled/artifact.rs`

Implements a versioned `CompiledArtifact` that wraps a `CompiledPlan` with a version header and a checksum, enabling serialization, compatibility detection, and corruption detection.

## Steps

1. [x] Create `crates/incin-core/src/compiled/artifact.rs`.
2. [x] Export `pub mod artifact;` in `crates/incin-core/src/compiled/mod.rs` and re-export key types.
3. [x] Implement `ArtifactVersion`, `ArtifactHeader`, and `CompiledArtifact` with `serialize`, `deserialize`, and `verify_integrity`.
4. [x] Create integration test suite `crates/incin-core/tests/compiled_artifact.rs`.
5. [x] Run `cargo test -p incin-core --test compiled_artifact`.
