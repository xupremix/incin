# UX-009 — axes! macro with ambiguous and missing-axis diagnostics

**Theme:** ux  
**Tier:** preview  
**Deps:** SHP-007  
**Target:** `crates/incin-macros/src/axes.rs`  

Implements the `axes!` procedural macro in `incin-macros` for named axis specification, validating axis uniqueness and emitting span-located diagnostics for ambiguous (duplicate) or missing axes.

## Steps

1. [ ] Create `crates/incin-macros/src/axes.rs` implementing `axes(input: TokenStream) -> TokenStream`.
2. [ ] Re-export `pub fn axes` in `crates/incin-macros/src/lib.rs` and `incin::prelude`.
3. [ ] Parse single identifiers or paths representing named axes (`axes![N, C, H, W]`).
4. [ ] Detect duplicate/ambiguous axis identifiers and return `syn::Error` diagnostics.
5. [ ] Expand valid axis lists to type-level tuple of `NamedDyn<Tag>`.
6. [ ] Create integration test `crates/incin-macros/tests/axes_macro.rs` and trybuild compile-fail suite in `crates/incin-macros/tests/axes_compile_fail/`.
7. [ ] Run `cargo test -p incin-macros --test axes_macro`.
