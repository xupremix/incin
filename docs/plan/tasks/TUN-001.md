# TUN-001 — Stable tuning identities

1. [x] Replace CUDA ordinal plus compute capability in the live kernel
   `TuningKey` with persistent device and compiler identity.
2. [x] Query canonical CUDA UUID, architecture, driver version, NVRTC version,
   compiler target, and semantic compiler-option identity.
3. [x] Provide statically typed backend identities and matching `Dyn`
   construction/projection checks.
4. [x] Provide a type-level nonzero topology world and matching `Dyn` world
   checks.
5. [x] Reject physical-device aliases, invalid/duplicate links, and invalid
   process layouts.
6. [x] Hash rank mapping, link classes, transport/version, and layout with a
   stable length-delimited encoding.
7. [x] Prove ordinal remapping cannot change identity while distinct UUIDs at
   the same process-local ordinal cannot alias.
8. [x] Add compile-fail evidence for static backend and zero-world mistakes.
