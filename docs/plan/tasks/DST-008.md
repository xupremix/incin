# DST-008 — DP=2 networked training

The first data-parallel topology is exactly two model replicas in separate
processes on network-accessible CUDA hosts. Each rank evaluates its local batch
shard, then mean-reduces parameter gradients before the optimizer step.

1. [x] Define `TwoRankDataParallel` as `MeshSpec<Data<U2>>`, with tensor and
   pipeline degrees fixed at one.
2. [x] Define `DataParallelDType`: `f16`, `bf16`, `f32`, `f64`, and `Dyn`.
   Static integer/quantized gradients are compile errors; `Dyn` rejects the
   same runtime dtypes.
3. [x] Build every gradient as `Partial<Mean> -> Replicated` on the data axis,
   with automatic sequence dependencies.
4. [x] Give every parameter a stable nonzero `GradientId` and include it in
   the collective plan hash, so swapping equally shaped parameters fails
   preflight.
5. [x] Reject duplicate/reserved gradient identities, empty plans, bad ranks,
   wrong meshes, and non-DP collective descriptors.
6. [x] Add direct CUDA-storage execution that checks identity, dtype, element
   and byte counts, device, layout, placement, and sequence before NCCL.
7. [x] Expose gradient synchronization through typed `Tensor`; replace the
   matching entry in `CudaGrads` so existing optimizers consume the synchronized
   value.
8. [x] Prove mean-gradient and one-step SGD parity on the deterministic
   reference transport for static `f32` and runtime `Dyn`/`f64`.
9. [x] Compile the two-host facade harness and run its static and `Dyn` local
   CUDA forward/backward paths on the available GTX 1650 SUPER.
10. [ ] Run the full ignored harness concurrently on two network-accessible
    CUDA/NCCL hosts and record numerical, gradient, and updated-weight parity.

## Local evidence

```text
cargo test -p incin-core --features distributed --test data_parallel
5 passed; 0 failed, including 3 compile-fail cases

cargo test -p incin-backends --features distributed-reference \
  --test data_parallel_reference
2 passed; 0 failed

cargo test -p incin --features distributed-nccl --test dp2_network \
  -- --ignored --exact local_cuda_static_and_dyn_backward_paths_match
1 passed; 0 failed

cargo test -p incin --features distributed-nccl --test dp2_network --no-run
compiled
```

The compile-fail cases reject integer gradients, `Q8_0`, and a TP=2 mesh. The
runtime suite rejects every integer dtype plus `Q8_0` under `Dyn`. The reference
step compares the mean of two local gradients and the resulting SGD update with
the full-batch calculation.

## Required two-host evidence

```text
# host 0
INCIN_RANK=0 INCIN_WORLD_SIZE=2 INCIN_RUN_ID=dp-example \
INCIN_LOCAL_CUDA_DEVICE=0 INCIN_RENDEZVOUS_ADDR=0.0.0.0:29510 \
INCIN_RENDEZVOUS_TIMEOUT_MS=30000 \
  cargo test -p incin --features distributed-nccl --test dp2_network \
  -- --ignored --exact dp2_static_and_dyn_match_single_device

# host 1
INCIN_RANK=1 INCIN_WORLD_SIZE=2 INCIN_RUN_ID=dp-example \
INCIN_LOCAL_CUDA_DEVICE=0 INCIN_RENDEZVOUS_ADDR=<host-0-ip>:29510 \
INCIN_RENDEZVOUS_TIMEOUT_MS=30000 \
  cargo test -p incin --features distributed-nccl --test dp2_network \
  -- --ignored --exact dp2_static_and_dyn_match_single_device
```

Both ranks must report the same local CUDA numerical parity, averaged parameter
gradient, and updated weight for static `f32` and runtime `Dyn(F32)`. Until that
output exists, DST-008 remains active rather than complete.
