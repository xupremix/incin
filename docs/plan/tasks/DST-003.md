# DST-003 - distributed placement rules

`DST-001` proves a logical topology and `DST-002` binds one to a machine.
Neither says how a tensor is distributed over it. This row adds that missing
logical proof layer without adding tensor storage, a collective transport, or a
planner.

1. [x] Extend `dist::placement` with `Replicated<Mesh>`,
   `Sharded<Mesh, Axis>`, `Partial<Mesh, Reduction>`, and
   `PipelineStage<Mesh, INDEX>`. Every distributed `Placement` implementation
   requires `Mesh: ValidMesh`.
2. [x] Extend `PlacementKind` with the runtime projection of those typestates,
   plus `PlacementBuf` for operation inputs and type-level reduction markers.
3. [x] Add `ShardDivisible<Degree>` over typenum `Div` and `Rem`. The impl
   exists only when the remainder is exactly `U0`; `Local` projects the
   quotient.
4. [x] Add `LegalTransition<To>` and `PlacementTransition` for identity,
   local shard, all-gather, all-reduce, and reduce-scatter. Mesh-changing and
   pipeline-stage-changing moves have no direct implementation.
5. [x] Make `Partial` a non-complete placement. `ReduceShardedAxis` produces
   that state, while `CompletePlacement` and `ElementwisePlacement` let ordinary
   consumers and elementwise rules reject it at compile time.
6. [x] Add runtime guards for dynamic shard divisibility, unsupported remainder
   policies, tensor-axis bounds, and pipeline-stage bounds.
7. [x] Add `DistributedRule`, `DistributedInputs`, and
   `PlacementTransitionRule`. The rule cross-checks the typed global shape
   against the operation descriptor, input placement projections, mesh-derived
   rank count and shard degree, and every local shape before minting
   `ValidatedDistributed`.
8. [x] Seal `ValidatedDistributed` like `Validated`: private fields, a
   crate-private constructor, and public read-only accessors.
9. [x] Add `placement_rules` with positive compile-time assertions, runtime
   checks, and seven trybuild rejections whose recorded output is checked for
   the intended error.
10. [x] Run the row evidence plus formatting, lint, no-std, documentation,
    workspace tests, and repository policy checks.

## Boundaries

**No tensor storage changes.** `Tensor<..., P = Local>`, global/local metadata,
and reshard invariants are `DST-004`. This row validates placement descriptors;
it does not attach them to tensor storage.

**No executable collective plan.** `PlacementTransition` states which movement
a legal transition requires. Group ids, sequence tokens, stream ordering, and
divergence preflight are `DST-007`; recording them here would make this logical
proof depend on a planner that does not exist yet.

**No physical identity in `PlacementKind`.** A typestate can project its
logical category, axis, reduction, or stage from a static method. It cannot
project the `MeshId` that only `DeviceMesh::bind` can compute from a runtime
topology fingerprint. Execution carries the bound mesh separately.

**Remainder policies are explicit but only `Reject` executes.** `PadAndMask`
needs an operation-specific neutral value and `Ragged` needs variable-count
collectives and kernels. Selecting either before those semantics exist returns
`UnsupportedRemainderPolicy`.

**Pipeline cardinality is a runtime guard on stable Rust.** The public
typestate keeps the RFC's `const INDEX: usize`; comparing that const with
`M::PIPELINE` in a generic bound requires unstable generic const expressions.
Same-stage identity is a compile-time transition, while
`validate_pipeline_stage` checks a bound mesh's runtime degree.

## Outcome

`ShardDivisible` has one blanket implementation, and its zero-remainder bound
is the proof. A static `U10` over `U3` has no implementation and fails to
compile; a runtime extent of ten over three reaches the same rule as
`DistributedError::NonDivisible`.

Transitions are similarly constructive. A replicated value can become an
equal shard locally; a shard becomes replicated through all-gather; a partial
becomes replicated through all-reduce or remains sharded through
reduce-scatter. There is no blanket transition, so changing meshes, consuming a
partial value as complete, producing a partial as if it were a reshard, or
silently sending between pipeline stages are all trait-bound failures.

`PlacementTransitionRule` is the only public checked path in this row that
mints `ValidatedDistributed`. It accepts untrusted runtime metadata, ties the
global result back to a `Shape` type and an `OperationSpec`, verifies the input
typestate projections, and proves either equal replication or an exact,
contiguous shard partition. Rank-local metadata has to contain `M::WORLD`
entries, a sharded extent divides by `M::TENSOR`, and a pipeline stage is checked
against `M::PIPELINE`; a caller-supplied vector cannot define any of those
degrees. The wrapper then exposes the result without exposing a constructor or
any field.

The evidence command carries `--features distributed`. The ledger's original
command omitted it, but Appendix B requires this Preview row behind a
non-default feature; an ungated command would otherwise report success after
running zero tests.
