# DST-005 - deterministic reference collectives

`DST-002` defines the physical-topology observation seam and `DST-003` names
the movements placements require. This row defines the transport-neutral
collective contract and a deterministic host implementation that can exercise
its rules without CUDA hardware.

1. [x] Define dtype-indexed `CollectiveBackend` buffers, explicit group and
   stream identifiers, checked operation descriptors, events, and structured
   failures. The transport-neutral vocabulary now resides in core and is
   re-exported by the backend crate so DST-007 can consume it without a cycle.
2. [x] Give every collective an explicit adjoint: all-gather and
   reduce-scatter pair, all-to-all is inverted, and all-reduce retains its
   reduction/scaling semantics.
3. [x] Implement deterministic rank-ordered all-reduce, all-gather,
   reduce-scatter, and all-to-all for the supported scalar dtypes.
4. [x] Implement static/`Dyn` parity. Supported static dtype markers satisfy
   `CollectiveDType`; `Dyn` checks its `DTypeId` against the payload before
   executing the same operation.
5. [x] Reject `Q8_0` statically because its block encoding cannot satisfy the
   scalar element-count contract; reject the same selection dynamically.
6. [x] Implement `ReferenceTopology` and prove two CUDA ranks in separate
   `ProcessPerRank` processes connected by `LinkClass::Network` derive one
   `MeshId`.
7. [x] Fix the fingerprint defect that test exposed: local process rank remains
   inspectable but is not part of the shared job identity digest.
8. [x] Add feature forwarding, CI execution, documentation, and feature-budget
   inventory; run package and repository gates.

## Boundaries

`ReferenceTransport` moves typed host values. A `ReferenceTopology` describing
CUDA device identifiers is a deterministic fixture for `TopologyProbe`, not a
claim that the reference transport accesses CUDA memory.

`CollectivePlan` is DST-007. Transport methods accept explicit group, stream,
count, dtype, and operation values, but they do not decide graph order or mint
sequence tokens. Shared descriptor vocabulary lives in core; only buffer/event
ownership and execution remain backend concerns.

The reference transport has no implicit casting. Unsupported static dtypes do
not compile; a `Dyn` buffer with mismatched runtime dtype returns a structured
error before reduction or movement begins.

## Outcome

The seven-case integration suite covers deterministic results, scaling,
adjoints, inverse all-to-all, `Dyn` dtype parity, count/divisibility/overflow
failures, static unsupported-dtype rejection, and the required two-rank network
topology. The full `distributed-reference` package suite passes with no device
dependency.
