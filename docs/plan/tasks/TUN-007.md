# TUN-007 — Tuning telemetry, provenance, and explain output

**Theme:** tune  
**Tier:** preview  
**Deps:** TUN-003  
**Target:** `crates/incin-backends/src/tuning/telemetry.rs`  

Exposes structured tuning telemetry, environment provenance records, and human/JSON explain formatters for autotuning decisions.

## Steps

1. [ ] Create `crates/incin-backends/src/tuning/telemetry.rs` (and re-export in `incin-backends::tuning::telemetry`).
2. [ ] Define `TuningProvenance` capturing environment fingerprint, candidate digest, winner selection source, median runtime, and sample count.
3. [ ] Define `TuningExplain` providing `explain_text()` and `explain_json()` for human-readable and JSON diagnostic outputs.
4. [ ] Define `emit_tuning_event` / `emit_tuning_telemetry` hooks integrating with process-global telemetry emitters.
5. [ ] Add unit and integration tests in `crates/incin-backends/tests/tuning_telemetry.rs` (and trybuild compile-fail tests if needed).
6. [ ] Run `cargo test -p incin-backends --features autotune,telemetry`.
