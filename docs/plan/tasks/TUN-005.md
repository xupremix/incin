# TUN-005 - Pointwise, reduction, and normalization CUDA tuning parity

**Theme:** tune  
**Tier:** preview  
**Deps:** TUN-004

Integrates the autotuning framework (`TUN-001..004`) with CUDA pointwise, reduction, and normalization operation kernel choices.

## Steps

1. [x] Extend CUDA pointwise kernel launcher in `crates/incin-backends/src/cuda/ops/elementwise.rs` to query `TuningService` for candidate kernel selection when `autotune` feature is active.
2. [x] Extend CUDA reduction kernel launcher in `crates/incin-backends/src/cuda/ops/reduce.rs` for autotuning warp vs block vs scalar reduction parameters.
3. [x] Extend CUDA normalization kernel launcher in `crates/incin-backends/src/cuda/ops/norm.rs` for autotuning layer_norm and batch_norm tile shapes.
4. [x] Add tuning parity unit tests in `crates/incin-backends/src/tuning.rs` verifying that candidate generation and default selections match expected choices.
5. [x] Run `cargo test -p incin-backends --test tuning_pruning --features autotune`.

## Boundaries

Covers elementwise pointwise ops, reduction ops, and normalization ops. GEMM and Convolution autotuning are covered in `TUN-006`.
