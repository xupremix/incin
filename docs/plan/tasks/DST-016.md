# DST-016 — Global checkpoint manifest and explicit cross-mesh resharded load

Checkpoint compatibility across distributed training runs is defined at global parameter shape and named parameter identity. Loaders reshard explicit checkpoints for a new mesh topology.

1. [x] Define `GlobalCheckpointManifest` carrying format version, source topology metadata, and per-parameter global shape, DType, and placement metadata.
2. [x] Implement resource-bounded serialization/deserialization for global checkpoint manifests (`manifest.json` / postcard).
3. [x] Implement `save_checkpoint` producing a global manifest alongside parameter storage (safetensors or binary chunks).
4. [x] Implement `load_resharded_checkpoint` capable of loading parameters from a global manifest onto any target `DeviceMesh` and local rank placement.
5. [x] Support slice-based resharding along tensor-parallel (column/row) or data-parallel axes when loading onto a mesh with different degrees.
6. [x] Reject corrupted manifests, shape mismatches, or missing parameters with structured `Error::Msg`.
7. [x] Write `crates/incin-core/tests/checkpoint_reshard.rs` verifying save/load round-trips, cross-mesh resharding (e.g. TP=2 to local/TP=1), and rejection of invalid manifests.
