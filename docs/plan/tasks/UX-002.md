# UX-002 — mesh! macro with expansion, hygiene, span, and compile-fail tests

**Theme:** ux  
**Tier:** preview  
**Deps:** DST-001  
**Target:** `crates/incin-macros/src/mesh.rs`  

Implements the `mesh!` procedural macro in `incin-macros` for ergonomic, type-level `MeshSpec` construction with axis defaults, span-aware diagnostics, hygiene, and trybuild compile-fail tests.

## Steps

1. [ ] Create `crates/incin-macros/src/mesh.rs` implementing `mesh(input: TokenStream) -> TokenStream`.
2. [ ] Re-export `pub fn mesh` in `crates/incin-macros/src/lib.rs`.
3. [ ] Parse `dp`, `tp`, `pp` axis degrees with default `1` for omitted axes, validating unique keys and nonzero positive bounds.
4. [ ] Expand `mesh!` to `::incin::prelude::MeshSpec<::incin::prelude::Data<::incin::prelude::U...>, ::incin::prelude::TensorParallel<::incin::prelude::U...>, ::incin::prelude::Pipeline<::incin::prelude::U...>>`.
5. [ ] Create integration test `crates/incin-macros/tests/mesh_macro.rs` and trybuild compile-fail suite in `crates/incin-macros/tests/mesh_compile_fail/`.
6. [ ] Run `cargo test -p incin-macros --test mesh_macro`.
