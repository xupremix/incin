**Theme:** ux

Implements the `placement!` procedural macro in `incin-macros` for compile-time placement construction with grammar validation, operation bounds, and span-located compile-fail diagnostics.

1. [ ] Create `crates/incin-macros/src/placement.rs` implementing `placement(input: TokenStream) -> TokenStream`.
2. [ ] Re-export `pub fn placement` in `crates/incin-macros/src/lib.rs`.
3. [ ] Parse `Local`, `Replicated on Mesh`, `Sharded(axis) on Mesh`, `Partial(Op) on Mesh`, and `PipelineStage(stage) on Mesh`.
4. [ ] Validate required `on Mesh` target for distributed placements and check reduction operators and non-negative stage indices.
