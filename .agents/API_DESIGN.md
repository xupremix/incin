# API Design - see `docs/API_DESIGN.md`

The public-API visibility policy lives in
[`docs/API_DESIGN.md`](../docs/API_DESIGN.md) and applies to every
contributor, human or agent.

Do not restate it here. A second, divergent copy of a policy is the same
failure mode as a competing roadmap: this file previously paraphrased the
policy in different words, and the two drifted - the paraphrase had gained a
rule the canonical copy lacked. That rule has been merged upstream.

See `PROPOSALS.md` §2.10 and `GOV-007`.
